# 📘 Assignment: Building REST APIs with FastAPI

## 🎯 Objective

Learn how to build a simple REST API using FastAPI. This assignment teaches creating endpoints, handling JSON requests and responses, and working with path and query parameters.

## 📝 Tasks

### 🛠️ Create the main API endpoints

#### Description
Build a FastAPI application that exposes multiple REST endpoints for interacting with a small example service.

#### Requirements
Completed program should:

- Use `FastAPI` to create an API instance and define routes
- Implement at least two endpoints with different HTTP methods
- Return JSON responses for each endpoint
- Use path parameters to identify a resource
- Use query parameters for optional request data

### 🛠️ Add request validation and response handling

#### Description
Enhance your API by validating incoming data and returning clear responses for successful and failed requests.

#### Requirements
Completed program should:

- Accept JSON input in at least one endpoint
- Validate required fields and return an appropriate status code when data is missing
- Return a success response with a JSON payload
- Include example usage or request format in comments or the program documentation

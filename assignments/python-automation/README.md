# 📘 Assignment: Automating Tasks with Python Scripts

## 🎯 Objective

Teach students how to automate repetitive tasks using Python scripts. This assignment focuses on file handling, text processing, and command-line interaction to make everyday workflows faster.

## 📝 Tasks

### 🛠️ Build a file organizer script

#### Description
Create a Python script that scans a folder and organizes files into subfolders based on file type.

#### Requirements
Completed program should:

- Accept a source directory path from the user
- Create subfolders for at least three file categories (e.g., documents, images, archives)
- Move files into the correct category folder
- Leave non-matching files in place or place them in an "other" folder

### 🛠️ Add text search and reporting

#### Description
Enhance the script so it can search text files for a keyword and report which files contain it.

#### Requirements
Completed program should:

- Prompt the user for a search keyword
- Search `.txt` files in the source directory
- Print a list of filenames that contain the keyword
- Show how many files matched the search
